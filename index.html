Bantuan & Panduan
1. Menulis Catatan: Ketuk tanggal mana saja di kalender untuk membuka kanvas catatan tanggal tersebut. Catatan langsung disimpan ke Supabase (cloud).
2. Multi-Profil: Ketuk tombol profil di pojok kanan atas untuk berpindah profil atau membuat profil baru (misal: Kerja, Pribadi, Proyek).
3. Indikator Status: Pil kecil di header menunjukkan kondisi sinkronisasi: ☁️ Sinkron (aman), ⚠️ Gagal (ada error — baca panel merah di bawah), 📴 Mode Lokal (pustaka cloud tak termuat).
4. Kalau Ada Error: Pesan error asli muncul otomatis di panel merah bawah layar. Ketuk Diagnostik & Log untuk detail, salin, atau tes koneksi.
5. Backup Data: Menu Ekspor/Impor untuk mengunduh salinan JSON, atau mengunggah data lokal lama ke Supabase.
Tentang Aplikasi
Kalender Canvas v27 Aplikasi Kalender Masehi + Hijriyah + Pasaran Jawa + Canvas Multi-Profil dengan sinkronisasi Supabase.
